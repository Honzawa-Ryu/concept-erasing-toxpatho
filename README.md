# concept-erasing-toxpatho

**ステータス: 完了(2026-08-13)**

## 概要

TG-GATEs肝臓病理WSI(998スライド)のUNI(病理基盤モデル)埋め込みに対し、概念消去
(concept erasure)を適用し、「バッチ(試験間差)を消しても病理所見の判別性能(has_finding)
を壊さずに済むか」を検証したプロジェクト。

背景: 別プロジェクト(wsi-ad)の非対照SSL手法比較で、埋め込み分散の55〜87%がスライド
identity(=試験間差/バッチ)で説明されてしまう、という問題が見つかった
(wsi-ad/TODO.md C章「試験間差除去の表現学習」)。本プロジェクトはその一次検証として、
UNIという既存の基盤モデル埋め込みに対し事後的な概念消去(C4「事後補正」に相当)を適用し、
バッチ除去と生物学的シグナル保持がどこまで両立するか(C5)を実データで検証した。

消去手法は2種類を比較: **LEACE**(線形消去)と**QuadraticEraser**(非線形消去、
連続ラベルは分位点で離散化して使用)。

## 結論

- **ぼやけ(blur)という具体的な構造アーティファクトは、病理所見シグナルと分離できる**。
  LEACE/QuadraticEraserどちらでぼやけを消してもhas_finding ROC-AUCはほぼ無傷
  (0.798 → 0.797 / 0.786)。パッチ単位で見ても、消去前後でtop異常パッチはほぼ同一
  (comparison-ad-toxpathoの可視化実験で確認)。
- **一方、スライドID(バッチ)識別性そのものを丸ごと消すと、病理所見シグナルもほぼ道連れで
  壊れる**。η²_slideは0.325→0.015(LEACE)/ほぼ0(QuadraticEraser)まで正しく下がる
  (消去自体は機能している)一方、has_finding ROC-AUCは0.798→0.338(LEACE、chance未満)
  /0.500(QuadraticEraser、chanceそのもの)まで崩壊する。
- **解釈**: この998スライドのTG-GATEsデータでは、「バッチ(スライド)」と「病理所見の
  有無」が強く絡み合っている(同一試験・同一化合物・同一用量群のスライドが同じ所見
  ラベルを共有しやすい実験デザイン上、自然な帰結とも言える)。wsi-ad/TODO.md C5
  「バッチ除去↔生物シグナル保持のトレードオフはどこまで両立するか」への一次的な答え:
  **粒度を選べば(特定の構造アーティファクト単位)両立するが、バッチ識別性そのものを
  丸ごと消す粗い介入では両立しない**。
